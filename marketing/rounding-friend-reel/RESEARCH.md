# Research and attribution

Primary documentation inspected for this reel:

| Project | Evaluation / actual use |
| --- | --- |
| [Hyperframes](https://github.com/heygen-com/hyperframes), [HTML schema](https://github.com/heygen-com/hyperframes/blob/main/docs/reference/html-schema.mdx) | Researched seekable HTML-to-video architecture. Inspired the timestamp-to-frame approach. No code or dependency copied into this project. |
| [Motion Canvas](https://github.com/motion-canvas/motion-canvas) | Considered for authored motion. A framework was unnecessary for six short SVG scenes. Not used. |
| [Remotion licensing](https://www.remotion.dev/docs/license/pricing) | Considered for React/video rendering; avoided an extra framework and licensing dependency. Not used. |
| [Kokoro ONNX](https://github.com/thewh1teagle/kokoro-onnx) | Actually used locally for English fictional character voices; wrapper version 0.6.1, MIT. |
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | Voice model, Apache 2.0. Model weights are not redistributed here. |
| [ONNX releases](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0) | Source for `kokoro-v1.0.int8.onnx` and `voices-v1.0.bin` when rebuilding voices. |
| [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans) | Embedded fonts matching QualiFi's branding, SIL Open Font License. License files included under assets. |

Implementation: original HTML/CSS/SVG and JavaScript, Playwright-controlled Chromium screenshots and FFmpeg H.264/AAC encoding. It does not use GSAP, Hyperframes, Motion Canvas or Remotion at runtime. The standalone HTML has no network dependencies. Audio timing derives from the locally synthesized clips; subtitles are split into readable chunks within each cue, rather than forced word alignment.

Music, coin chimes, interruption sweep and cartoon pop are original procedural audio generated by `make_audio.py`. No commercial music, stock footage or external character images are used. The existing QualiFi mark remains the user's brand asset. Keep the bundled font/license notices when redistributing editable source. This project does not grant rights to the QualiFi brand.
